# Thesis

Шаблон для оформления пояснительных записок, отчётов по НИР и лабораторных работ
МИФИ, свёрстанный на [Typst](https://typst.app) — современном инструменте для вёрстки.

> **Для ИИ-агентов:** канонические правила работы с шаблоном — в
> [AGENTS.md](AGENTS.md), подробное руководство со всеми каркасами файлов,
> примерами подписей, библиографии и чек-листом проверки — в
> [docs/agent-report-guide.md](docs/agent-report-guide.md). Прочитайте их перед
> созданием или правкой отчёта.

## Устройство

Шаблон разделён на несколько основных частей:

- `main.typ` — главный файл проекта, точка входа; содержит глобальные настройки
  всей ПЗ (поля страниц, общий шрифт, настройки переносов), подключает титульник,
  лист задания и `contents.typ`.
- `preamble.typ` — вспомогательные переменные (тема, название работы, ФИО и т.д.)
  и helper-функции (`table_figure`, `file_listing`, `text_xpt`, `underlined`).
- `contents.typ` — структура основной части записки (всё вне титульника и задания):
  реферат, оглавления, правила оформления фигур, порядок глав, библиография, приложения.
- `title/` — вёрстка титульного листа (данные берёт из `preamble.typ`).
- `task/` — вёрстка листа задания: `task.typ` (титульная часть) и `task_table.typ`
  (таблица заданий по пунктам).
- `chapters/` — содержательные разделы записки; здесь же `biblio.bib` (источники)
  и `.csl`-файл со стилем ГОСТ для списка литературы.
- `appendices/` — приложения (обычно крупные листинги кода).
- `listings/`, `images/` — внешние листинги кода и изображения, вставляемые в записку.
- `biblio.typ` — объявление библиографии. Импортируется в главах с цитатами, чтобы
  языковой сервер Typst видел ключи `@cite` при правке отдельного файла; сам список
  литературы выводится один раз в `contents.typ` (подробнее — в руководстве для агентов).

## Сборка

Для сборки нужен **компилятор Typst** (шаблон проверен на версии **0.14.2**;
требуется свежая версия, не ниже 0.13 — иначе современный синтаксис не соберётся).
На macOS ставится просто:

```
$ brew install typst
```

Собрать записку можно вручную

```
$ typst compile main.typ main.pdf
```

либо через Makefile:

```
$ make
```

Очистка артефактов сборки:

```
$ make clean
```
